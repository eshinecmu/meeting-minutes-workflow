## 实现

- `infra/minutes_store.py` 启用既有 minutes_version：结构、Markdown、含问题清单的 note 均使用既有 FileCipher 加密后存入 TEXT。单会议锁与 SQLite IMMEDIATE 事务内 max+1，配对指纹相同复用原行。
- assemble 保存 system 草稿；G3 edit 在复检、同步后保存实际操作者草稿。源 / 模板 / 结构 / Markdown 指纹纳入既有 IdempotencyStore，登记后断电可重算并复用配对版本。
- 图导出显式传入配对快照；ExportService 独立复检后比对快照，渲染实际纪要。G3 后复检通过才标 final。图缓存、服务文件复用、归档及下载均设防线；旧记录稿缓存不能当作纪要交付。
- POST /export 支持 artifact=record|minutes；有工作流检查点或纪要版本时默认 minutes，其余保持记录稿默认行为。显式记录稿独立导出，文件名及 Electron 选择器标“记录稿”；失败纪要默认导出不回退。version 只解释所选类型，缺失报不存在。
- 不重建旧历史。按较窄口径处理旧稿：Markdown 无法无损同步时返回 E4001，缺源返回 E3002；缺配对版本的旧归档不补历史或重生成文件。现有归档文件不追溯删除。
