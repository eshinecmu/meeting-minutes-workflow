## 0. 怎么用这份文档

这份文档是**任务卡合集**。每个施工卡包含：任务目标 → 前置依赖 → 输入输出 → 实现步骤 → 关键代码骨架 → 验收标准 → 常见坑。

**施工纪律（必须遵守）**：

1. **按卡号顺序做**，不要跳卡。卡与卡之间有依赖，跳卡会导致返工。
2. **每次只做一张卡**。做完 → 跑验收命令 → 通过了再进下一张。
3. **卡内的"验收标准"是硬门槛**，不是建议。不通过不许标完成。
4. **不许改架构**。技术栈、目录结构、接口签名以《架构设计说明书》为准。有异议走变更流程（SAD 附录 D）。
5. **遇到不确定，先查文档，再问**。文档里写了的东西不要问。

**卡号规则**：`T<阶段>-<序号>`，例如 `T1-03` 表示一期第 3 张卡。

**工期估算口径**：以"一个熟悉 Python 的中级开发，每天有效编码 6 小时"计。估时不含联调等待、不含需求变更。

### 1.4 首次提交前必须写的两个检查脚本

**`tools/check_layers.py`**（对应 SAD C01）

```python
"""层次依赖检查：领域层禁止 import 框架与网络库。
退出码 0 = 通过；1 = 违规。
"""
import ast
import sys
from pathlib import Path

FORBIDDEN_IN_DOMAIN = {
    "fastapi", "starlette", "uvicorn", "sqlite3", "sqlalchemy",
    "httpx", "requests", "torch", "funasr", "ollama", "langgraph",
    "pydub", "docx",   # python-docx 仅允许出现在 domain/docx 下，见下方白名单
}

# domain/docx 是唯一例外：它需要 python-docx 做样式映射，
# 但必须通过 domain/docx/_docx_backend.py 单点隔离
DOMAIN_DOCX_ALLOW = {"docx"}


def check_file(path: Path, module_name: str) -> list[str]:
    errors: list[str] = []
    tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
    for node in ast.walk(tree):
        mods: list[str] = []
        if isinstance(node, ast.Import):
            mods = [a.name.split(".")[0] for a in node.names]
        elif isinstance(node, ast.ImportFrom) and node.module:
            mods = [node.module.split(".")[0]]
        for m in mods:
            if m in FORBIDDEN_IN_DOMAIN:
                if m in DOMAIN_DOCX_ALLOW and "domain/docx" in str(path).replace("\\", "/"):
                    continue
                errors.append(f"{path}:{node.lineno} 领域层禁止 import '{m}'")
    return errors


def main() -> int:
    root = Path(__file__).resolve().parent.parent / "src" / "mmwf" / "domain"
    all_errors: list[str] = []
    for py in root.rglob("*.py"):
        all_errors.extend(check_file(py, py.stem))
    if all_errors:
        print("\n".join(all_errors))
        print(f"\n✗ 层次依赖检查未通过，共 {len(all_errors)} 处违规")
        return 1
    print("✓ 层次依赖检查通过")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

**`tools/check_deps.py`**（对应 SAD C09/C10）

```python
"""依赖白名单检查：禁止引入红线依赖（SAD §7.1）。"""
import re
import sys
from pathlib import Path

BANNED = [
    # (正则, 说明)
    (r"\bsensevoice\b", "SenseVoice 官方已标注停止服务，禁止引入"),
    (r"\bwhisper[-_]?large[-_]?v3\b", "Whisper-large-v3 中文字错率 20.02%，禁止作主引擎"),
    (r"\bpyannote\b", "需 HuggingFace 令牌申请，内网构成流程障碍"),
    (r"\bdify\b", "重平台，与离线要求冲突"),
    (r"\bopenai\b", "云 SDK，禁止引入"),
    (r"\bazure[-_]", "云 SDK，禁止引入"),
    (r"\bdashscope\b", "云 SDK，禁止引入"),
    (r"\bposthog\b|\bsentry[-_]sdk\b|\bsegment\b", "遥测 SDK，禁止引入"),
]


def main() -> int:
    lock = Path(__file__).resolve().parent.parent / "requirements.lock"
    if not lock.exists():
        print("! requirements.lock 不存在，跳过（首次生成前）")
        return 0
    text = lock.read_text(encoding="utf-8").lower()
    hits: list[str] = []
    for pattern, reason in BANNED:
        if re.search(pattern, text):
            hits.append(f"✗ 检出禁用依赖 {pattern}：{reason}")
    if hits:
        print("\n".join(hits))
        return 1
    print("✓ 依赖白名单检查通过")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## 2. 编码规范（团队统一口径）

### 2.1 命名

| 对象 | 规范 | 示例 |
|:---|:---|:---|
| 模块 / 包 | 小写下划线 | `topic_extractor.py` |
| 类 | 大驼峰 | `TopicExtractor` |
| 函数 / 变量 | 小写下划线 | `merge_topics` |
| 常量 | 大写下划线 | `DEFAULT_CHUNK_OVERLAP` |
| SQL 表名 | 小写下划线，单数 | `transcript_segment` |
| SQL 列名 | 小写下划线 | `source_refs` |
| 接口 / 协议 | 以能力命名，不加 `I` 前缀 | `AsrProvider`（不是 `IAsr`） |
| 中文相关变量 | 允许拼音但须有意义，**禁止** `a1`/`tmp2` | `hotwords`、`meeting_title` |

### 2.2 类型与数据结构

- 跨层传递**一律用 frozen dataclass**（SAD §6.2）。字段必须带类型注解，`mypy --strict` 对 `domain/` 通过。
- 需要序列化给 LLM 或前端的用 pydantic `BaseModel`。
- **禁止**跨层传裸 dict。若必须（如 `payload`），须在进入领域层前过 pydantic 校验。
- 时间一律用 **UTC 毫秒整数**（`*_ms`）或 **ISO8601 字符串**（`*_at`），不混用。音频时间戳统一 `int` 毫秒。

### 2.3 中日韩文本处理三条铁律

这三条是被坑出来的，必须遵守：

1. **所有文件 I/O 显式指定 `encoding="utf-8"`**。Windows 默认 GBK，不指定必乱码。
2. **写含中文的脚本文件（尤其是 `.ps1` / `.bat`）必须存为 UTF-8 with BOM**。否则 Windows PowerShell 按 GBK 解码 → 路径乱码 → 静默失败且不报错。
3. **正则处理中文时不要用 `\w`**，用显式字符类。`\w` 在 Unicode 模式下包含中文，会导致意想不到的匹配。

### 2.4 错误处理

```python
# 正确写法：领域层抛领域异常，应用层翻译为错误码
# domain/extraction/extractor.py
class ExtractionError(Exception):
    """领域异常：抽取失败。"""

class SchemaViolationError(ExtractionError):
    def __init__(self, field_path: str, reason: str):
        self.field_path = field_path
        self.reason = reason
        super().__init__(f"schema violation at {field_path}: {reason}")

# api/errors.py 中集中翻译
ERROR_MAP = {
    SchemaViolationError: ("E3002", "纪要结构自检未通过，已自动重试。若反复出现，请核对文稿是否完整。"),
    ...
}
```

**禁止**：
- `except Exception: pass`（吞异常）
- 把堆栈信息返回给前端
- 在领域层抛 HTTP 相关异常

```python
# src/mmwf/infra/crypto.py
import os
from cryptography.hazmat.primitives.ciphers.aead import AESGCM

class FileCipher:
    """AES-256-GCM 文件加密。密钥由 OS 凭据管理器保管。"""
    def __init__(self, key: bytes):
        if len(key) != 32:
            raise ValueError("AES-256 需要 32 字节密钥")
        self._aes = AESGCM(key)

    def encrypt_file(self, src, dst) -> str:
        """返回密文 sha256。格式：nonce(12) || ciphertext||tag"""
        nonce = os.urandom(12)
        data = src.read_bytes()
        blob = nonce + self._aes.encrypt(nonce, data, None)
        dst.write_bytes(blob)
        return hashlib.sha256(blob).hexdigest()

    def decrypt_file(self, src, dst) -> None:
        blob = src.read_bytes()
        nonce, ct = blob[:12], blob[12:]
        dst.write_bytes(self._aes.decrypt(nonce, ct, None))
```

> **密钥来源（一期简化方案）**：Windows 用 `win32cred` 写 Credential Manager；Linux 用 `keyring`。**禁止**把密钥明文写在配置文件或代码里。若一期来不及接 OS 凭据管理器，则**必须在部署手册中明确标注"当前版本密钥存储为待加固项"**，不得默不作声。

**`infra/filestore.py` 职责**

```python
# src/mmwf/infra/audit.py
import hashlib, json
from datetime import datetime, timezone

class AuditLogger:
    """审计日志：仅 INSERT + 链式哈希。"""
    ACTIONS = {
        "login", "logout", "import_audio", "import_text",
        "transcribe_start", "transcribe_done",
        "segment_edit", "gate_decision", "export", "export_undo",
        "glossary_change", "template_change", "selfcheck",
    }

    def __init__(self, engine):
        self._engine = engine

    def log(self, operator: str, action: str, target_type: str | None = None,
            target_id: str | None = None, detail: dict | None = None,
            result: str = "success") -> None:
        if action not in self.ACTIONS:
            raise ValueError(f"未登记的审计动作: {action}")
        ts = datetime.now(timezone.utc).isoformat()
        detail_json = json.dumps(detail or {}, ensure_ascii=False, sort_keys=True)
        prev_hash = self._last_hash()
        row_hash = self._compute_hash(prev_hash, ts, operator, action,
                                      target_type, target_id, detail_json, result)
        with self._engine.begin() as conn:
            conn.exec_driver_sql(
                "INSERT INTO audit_log (ts, operator, action, target_type, target_id,"
                " detail, result, prev_hash, row_hash) VALUES (?,?,?,?,?,?,?,?,?)",
                (ts, operator, action, target_type, target_id,
                 detail_json, result, prev_hash, row_hash),
            )

    @staticmethod
    def _compute_hash(prev, ts, operator, action, tt, tid, detail, result) -> str:
        raw = f"{prev}|{ts}|{operator}|{action}|{tt}|{tid}|{detail}|{result}"
        return hashlib.sha256(raw.encode("utf-8")).hexdigest()
```

```python
        self._model_name = model_name
        self._model_dir = model_dir
        self._device = device
        self._model = None

    def available(self) -> bool:
        try:
            import funasr  # noqa: F401
            return True
        except ImportError:
            return False

    def warmup(self) -> None:
        if self._model is None:
            self._model = AutoModel(
                model=self._model_name,
                model_revision="v2.0.4",
                vad_model="fsmn-vad",
                punc_model="ct-punc",

                disable_update=True,          # ← 关键：禁止联网检查更新
                disable_pbar=True,
            )

    def transcribe(self, audio_path, hotwords=None) -> TranscriptResult:

        if hotwords:

        raw = self._model.generate(input=str(audio_path), **kwargs)
        segments = self._normalize(raw, hotwords or [])

               / max(1, sum(1 for s in segments if s.confidence is not None)))
        warnings = self._detect_silent_failures(raw, segments, hotwords or [])

            segments=tuple(segments), avg_confidence=avg or None,
            engine="funasr", model=self._model_name,
            hotwords_applied=self._verify_hotwords(raw, hotwords or []),
            warnings=tuple(warnings),
        )
```

```python
def _detect_silent_failures(self, raw, segments, hotwords) -> list[str]:
    warns: list[str] = []
    # ① 时间戳数组与文本长度错位 —— 上游典型静默失效症状
    for s in segments:
        if s.words and abs(len("".join(w.text for w in s.words)) - len(s.text)) > max(3, len(s.text) * 0.1):
            warns.append(f"timestamp/text length mismatch at seq={s.seq}")
    # ② 热词零命中 —— 术语库非空但完全没生效
    if hotwords and not self._verify_hotwords(raw, hotwords):
        warns.append("hotwords supplied but zero hit; suspect hotword param ignored")
    # ③ 置信度全空 —— 引擎未返回置信度
    if all(s.confidence is None for s in segments):
        warns.append("engine returned no confidence; review gate degraded")
    return warns
```

```python
import subprocess, json
from pathlib import Path

SUPPORTED = {".wav", ".mp3", ".m4a", ".wma", ".amr", ".flac", ".aac", ".ogg"}

def probe_duration_ms(ffprobe: str, path: Path) -> int:
    out = subprocess.run(
        [ffprobe, "-v", "quiet", "-print_format", "json",
         "-show_format", str(path)],
        capture_output=True, text=True, encoding="utf-8", check=True,
    )
    info = json.loads(out.stdout)
    return int(float(info["format"]["duration"]) * 1000)


def build_chunk_plan(duration_ms: int, chunk_sec: int = 1800, overlap_sec: int = 50):
    """生成切分计划。相邻块重叠，避免在句中断开。"""
    step = chunk_sec - overlap_sec
    plan, start = [], 0
    while start < duration_ms:
        end = min(start + chunk_sec * 1000, duration_ms)
        plan.append({"seq": len(plan) + 1, "start_ms": start, "end_ms": end})
        if end >= duration_ms:
            break
        start += step * 1000
    return plan


def cut_chunk(ffmpeg: str, src: Path, dst: Path, start_ms: int, end_ms: int) -> None:
    subprocess.run(
        [ffmpeg, "-nostdin", "-y", "-ss", f"{start_ms/1000:.3f}",
         "-t", f"{(end_ms-start_ms)/1000:.3f}",
         "-i", str(src), "-ac", "1", "-ar", "16000", "-f", "wav", str(dst)],
        capture_output=True, check=True,
    )
```

> **采样率统一 16000 Hz 单声道**：这是 ASR 模型的标准输入，提前转换可让引擎少做一次重采样。

```python
# src/mmwf/domain/glossary/matcher.py
import re
from dataclasses import dataclass

@dataclass(frozen=True)
class GlossaryEntry:
    entry_id: str
    category: str      # org | person | term | codename
    canonical: str
    aliases: tuple[str, ...]
    enabled: bool = True


def build_alias_index(entries: list[GlossaryEntry]) -> dict[str, str]:
    """易错写法 → 规范写法。"""
    idx: dict[str, str] = {}
    for e in entries:
        if not e.enabled:
            continue
        for a in e.aliases:
            idx[a] = e.canonical
    return idx


def apply_corrections(text: str, alias_index: dict[str, str]) -> tuple[str, int]:
    """同音/近似错字回改。返回 (修正后文本, 命中数)。
    按别名长度倒序替换，避免短词先替换破坏长词。
    """
    hits = 0
    for wrong in sorted(alias_index, key=len, reverse=True):
        if wrong in text:
            hits += text.count(wrong)
            text = text.replace(wrong, alias_index[wrong])
    return text, hits


def export_hotwords(entries: list[GlossaryEntry], limit: int = 2000) -> list[str]:
    """导出给 ASR 的热词表。只取 canonical，不含 aliases。"""
    words: list[str] = []
    for e in entries:
        if e.enabled:
            words.append(e.canonical)
    return words[:limit]
```

```python
def needs_review(seg, thresholds) -> bool:
    """是否需要人工复核。"""
    if seg.confidence is not None and seg.confidence < thresholds["asr"]["low_confidence"]:
        return True
    flags = set(seg.flags or ())
    if "silence" in flags or "overlap" in flags:
        return True
    if len(seg.text.strip()) <= 1:          # 疑似残余噪声
        return True
    return False


def split_for_review(segments, thresholds):
    to_review = [s for s in segments if needs_review(s, thresholds)]
    auto_pass = [s for s in segments if not needs_review(s, thresholds)]
    return to_review, auto_pass
```

```python
def set_first_line_indent_chars(paragraph, chars: int) -> None:
    """首行缩进 N 字符（用 w:firstLineChars，随字号自适应）。"""
    pf = paragraph.paragraph_format
    ppr = paragraph._p.get_or_add_pPr()
    ind = ppr.find(qn("w:ind"))
    if ind is None:
        ind = OxmlElement("w:ind")
        ppr.append(ind)
    # firstLineChars 单位是 1/100 字符
    ind.set(qn("w:firstLineChars"), str(chars * 100))
    ind.set(qn("w:firstLine"), "0")     # 同时清掉绝对值，避免冲突

def fix_table_indent_penetration(table) -> None:
    """★ 修复表格段落被正文缩进穿透（F5.3，最高频的坑）。"""
    for row in table.rows:
        for cell in row.cells:
            for paragraph in cell.paragraphs:
                ppr = paragraph._p.get_or_add_pPr()
                ind = ppr.find(qn("w:ind"))
                if ind is None:
                    ind = OxmlElement("w:ind")
                    ppr.append(ind)
                # 全部清零
                for attr in ("w:firstLineChars", "w:firstLine",
                             "w:leftChars", "w:left",
                             "w:rightChars", "w:right",
                             "w:hangingChars", "w:hanging"):
```

```python
def check_no_indent_in_tables(docx_path: str) -> list[str]:
    """解压 docx，检查所有表格单元格内段落缩进为 0。"""

            tree = etree.fromstring(z.read(name))
```

```python
# src/mmwf/graph/interrupts.py
from langgraph.types import interrupt

def make_gate_g2(deps):
    def gate_g2(state: PipelineState) -> PipelineState:
        decision = interrupt({
            "gate": "G2",
            "gate_label": "待确认议题",              # 界面文案（N3.3）
            "payload": {"topics": state["topics"],
                        "resolutions": state["resolutions"],
                        "action_items": state["action_items"]},
            "risk": "high",
            "evidence": _collect_evidence(state),
        })
        if decision["decision"] == "edit":
            return {"topics": decision["payload"]["topics"],
                    "resolutions": decision["payload"]["resolutions"],
                    "action_items": decision["payload"]["action_items"]}
        if decision["decision"] == "approve":
            return {}
        raise _RejectedError("G2 rejected")
    return gate_g2
```

> **`interrupt()` 的语义**：调用即中断并持久化检查点；恢复时用 `Command(resume=<decision>)` 从该点继续。**这正是"edit 不重跑已完成节点"的实现基础**——`approve` 与 `edit` 都从 `gate_g2` 之后继续，只有 `reject` 通过条件边回到 `extract`。

**常见坑**
- LangGraph 的检查点**必须传 `thread_id`**（用 `meeting_id`），否则恢复时找不到状态。
- `interrupt()` **不能在节点外部调用**，且节点函数在中断时会被"重放"——**中断点之前的代码会再跑一次**。因此 gate 节点内**不能有副作用**（如写文件、写审计）。审计写入要在恢复后的下游节点做，或用 `idempotency` 保护。
- 节点的返回值是**状态增量**（partial update），不是完整状态。返回 `{}` 表示不改。
- `SqliteSaver` 的连接**不能让多个线程共用**，要按任务开独立连接。

```python
import socket, psutil   # psutil 需加入白名单

def selfcheck_network() -> dict:
    """枚举本进程出站连接，统计非回环连接数。"""
    proc = psutil.Process()
    outbound, listening = [], []
    for c in proc.net_connections(kind="inet"):
        raddr = c.raddr
        if raddr and raddr.ip not in ("127.0.0.1", "::1", "0.0.0.0"):
            outbound.append({"ip": raddr.ip, "port": raddr.port, "status": c.status})
        if c.status == psutil.CONN_LISTEN:
            listening.append(f"{c.laddr.ip}:{c.laddr.port}")
    return {
        "outbound_connections": len(outbound),
        "outbound_detail": outbound,
        "listening_ports": listening,
        "dns_queries_attempted": _count_dns_attempts(),
```

### T2-01 分块分层抽取引擎
**预估：3 天**

```python
# src/mmwf/domain/extraction/chunker.py
def chunk_segments(segments, target_chars=1500, overlap_chars=200) -> list[Chunk]:
    """按语义边界切块：
    优先级 ① 说话人切换 ② 话题转折词 ③ 长静音(>1.5s) ④ 字符数达标
    """
    TURN_WORDS = ("那么", "接下来", "第二个议题", "下面", "另外", "关于")
    chunks, buf, buf_chars = [], [], 0
    for seg in segments:
        buf.append(seg); buf_chars += len(seg.text)
        boundary = (
            seg.speaker != segments[seg.seq - 1].speaker
            if seg.seq > 0 else False
        ) or any(w in seg.text[:10] for w in TURN_WORDS) \
          or (seg.gap_after_ms or 0) > 1500
        if buf_chars >= target_chars and boundary:
            chunks.append(_make_chunk(buf, len(chunks) + 1))
            buf = _tail_overlap(buf, overlap_chars)     # 带重叠进入下一块
            buf_chars = sum(len(s.text) for s in buf)
    if buf:
        chunks.append(_make_chunk(buf, len(chunks) + 1))
    return chunks
```

```python
# domain/minutes/validator.py 中的 diff 工具
import difflib

def diff_versions(approved: str, edited: str) -> list[dict]:
    """返回逐段落差异，供前端渲染。
    目标：避免重复审阅已通过内容——只高亮变化的段落。
    """
    a = approved.splitlines()
    b = edited.splitlines()
    out = []
    for tag, i1, i2, j1, j2 in difflib.SequenceMatcher(None, a, b).get_opcodes():
        if tag == "equal":
            out.append({"type": "unchanged", "lines": a[i1:i2]})
        elif tag == "replace":
            out.append({"type": "changed", "old": a[i1:i2], "new": b[j1:j2]})
        elif tag == "delete":
            out.append({"type": "removed", "old": a[i1:i2]})
        elif tag == "insert":
            out.append({"type": "added", "new": b[j1:j2]})
    return out
```

| 敏感表述 | 命中 `readings_forbidden` | 进问题清单，建议替换 |
| 溯源完整性 | 每条结论都有 `source_refs` 且能匹配 | **硬拦截**，不得进入定稿（C04） |
| 粒度合规 | 责任人无空值；单条决议不含多事项 | 自动修正（填"暂无"、拆分），并记录 |

**关键约束**：`ungrounded` 结论**必须硬拦截**，不能只进"问题清单"就放行。这是红线项 4（结论无法溯源）与红线项 5（无依据编造）的技术保障。

```python
def validate_hard(state) -> list[Issue]:
    """硬校验：不通过即禁止进入 assemble。"""
    issues = []
    for topic in state["topics"]:
        if not topic.get("source_refs"):
            issues.append(Issue(level="error", code="UNGROUNDED_TOPIC",
                                target=topic["topic_id"],
                                message=f"议题「{topic['name']}」缺少原文依据"))
        for r in topic.get("resolutions", []):
            if not r.get("source_refs"):
                issues.append(Issue(level="error", code="UNGROUNDED_RESOLUTION",
                                    target=r["resolution_id"], message="议定事项缺少原文依据"))
    return issues
```

**验收标准**
- [ ] 构造一个无 `source_refs` 的 resolution → **流程被硬拦截**，报 `E3002` 级别的错误
- [ ] 构造一个责任人缺失的 resolution → 自动填「暂无」，问题清单中记录一条 `info`
- [ ] 构造含"差不多"的文本 → 问题清单命中禁用表述
- [ ] 数值一致性检查：纪要写"300 万元"而转写稿写"三十万" → 命中不一致告警
- [ ] 校验清单可导出为文本，供人工逐条核对

### T2-05 影子模式验证
**预估：持续 2—4 周（工程投入约 1 天）**

**目标**：系统生成但不交付；与人工定稿比对；一致率达标后放开（PRD §8.3 上线门槛）。

**比对维度**

| 维度 | 度量 | 阈值（建议，须与使用单位约定） |
|:---|:---|:---|
| 要素齐备度 | 系统稿含全部必填要素的比例 | ≥ 95% |
| 议题召回率 | 人工定稿中的议题被系统提及的比例 | ≥ 90% |
| 议定事项召回率 | 人工定稿中的议定事项被系统抽取的比例 | ≥ 85% |
| 无依据陈述率 | 系统稿中有转写稿无依据的陈述的比例 | **= 0**（红线） |
| 结构合规率 | 系统稿结构符合模板的比例 | 100% |

**放开策略（渐进授权）**

```
阶段 0：系统不生成，仅跑转写与记录稿（一期已交付）
  ↓ 达标：转写质量与记录稿可用性确认
阶段 1：系统生成，人工照常撰写，事后比对（影子模式）
  ↓ 达标：一致率 ≥ 阈值 且 分歧多为"系统更保守"
阶段 2：系统生成，人工在此基础上修改（半自动）
  ↓ 达标：返工轮次 ≤ 1 轮
阶段 3：放开自主使用，人工仅做审定
```

**验收标准**
- [ ] 影子模式运行 ≥ 20 份真实历史纪要
- [ ] 比对报告生成，五个维度全部达标
- [ ] **无依据陈述率严格为 0**（任一出现即回到阶段 1 重新验证）
- [ ] 分歧分析：分类记录"系统更保守""系统更激进""系统错误"，激进类必须归零

**常见坑**
- 影子模式**必须用真实历史纪要**，不能用构造的测试样例。构造样例无法暴露真实数据里的口语化、方言、专业术语问题。
- 比对是**人工评判**，不要指望自动化。可以做一个辅助比对界面，但最终判定要人做。
- 一致率不达标时，**优先改提示词与示例库，不要轻易上微调**（调研 §4.5：微调不注入新知识、事实会过时、有合规风险）。
